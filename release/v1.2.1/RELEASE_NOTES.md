# SpenTablet v1.2.1

手机端 `1.2.1`（versionCode 5）· PC 端 `1.2.1`。

## 修复

### PC 端崩溃（捕获 → 绘制 → 移动范围框 → 再绘制）
- **根因**：GDI+（System.Drawing）**不是线程安全的**。截图在 TCP 线程上跑
  `CopyFromScreen` + PNG 编码，而桌面备注叠加层在独立 UI 线程上用 GDI+ 画笔迹，
  两条线程偶发并发把 GDI+ 内部状态写坏，进程**无提示消失**——而且不留 Windows
  错误报告和转储，事后无从查起。
- **修复**：截图与笔迹绘制共用一把全局 GDI 锁，彻底串行化。
- **加固**：
  - 注册 `Application.ThreadException` + `UnhandledExceptionMode.CatchException`——
    以前 UI 线程异常只会弹对话框/静默退出，日志里一个字都没有；现在全部落日志。
  - `NoteOverlay.OnPaint`、`Post` 回调、`RegionFrame` 刷新全部 try/catch，单次异常不再带崩进程。
  - 修掉 `Pen.Brush` 每次取值新建 GDI 笔刷的句柄泄漏（改用复用的 `SolidBrush`）。
  - 记录 `ProcessExit`，下次能区分「正常退出」和「被外力终止」。
- 新增 `repro_crash.py`：按真实时序回放「备注→画笔→捕获→平移→再画」协议帧，用于回归。

### 其他修复
- **顶栏高度写死**（竖屏 56dp / 横屏 44dp）+ 状态文字单行省略：以前状态文字一换行/变空，
  顶栏跟着变高变矮，书写区尺寸抖动 → PC 端宽高比重算 → 范围框跳一下。
- **无极滚动惯性**：衰减从 0.92 收紧到 0.86，并加「速度阈值 + 600ms 上限」双保险——
  抬手后约 0.3 秒自然滑停，不再出现「不按停就一直滚」。

## 改进

- **手机屏笔迹颜色同步**：左侧色板换色后，手机屏上画的笔迹也用同一个颜色
  （每笔落笔时锁定，已画的笔不变色，与 PC 端行为一致）。
- **捕获按钮**：点击后文字由「清空」改为**「完成」**，再点完成即恢复。
- **滚动比例上限 30、默认 5.0**（老配置自动迁移一次）。
- **三指/四指左右滑**的可选动作补齐：后退/前进（按方向）、固定后退、固定前进、
  左/中/右键、切换模式、**音量加减、静音、下一任务、上一任务**；一次滑动只触发一次（450ms 冷却）。
