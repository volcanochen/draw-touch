# SpenTablet v1.1.0 发布说明

发布日期：2026-10-27

## 下载

| 文件 | 说明 |
|---|---|
| `SpenTabletPhone-v1.1.0.apk` | 手机端（Android 8.0+，建议 S Pen 机型） |
| `SpenTabletHost-win64-v1.1.0.zip` | PC 端（Windows 10/11，.NET 8 桌面运行时） |

## 新功能

### 触摸板模式（原鼠标模式，默认）
- **右侧虚拟滚轮条**：手指上下滑动直接滚动；**底部左/中/右键**直接点击，与笔记本触摸板对齐
- **光标速度 / 滚动比例可配置**（设置页 ± 调节）
- **双指/三指/四指手势可自定义动作**：滚动、缩放、左/中/右键、前进/后退、切换模式
- **触摸板颜色可配置**：暗灰 / 纯黑 / 深蓝 / 墨绿 / 酒红
- 触摸板模式下 S Pen 不再在手机屏上画轨迹（笔即鼠标）

### 数位板模式
- 新增**底部工具条**：
  - **屏幕备注**：开启后 S Pen 直接在 PC 桌面固定位置画笔迹（透明置顶、鼠标穿透，不随范围框移动）
  - **清除笔迹**：点击撤销一笔，长按清空
  - **截图**：点击捕获 PC 范围框画面传到手机全屏预览（点一下关闭）；捕获期间范围框锁定不可移动
- 数位板/触摸板模式手机端 UI 全面区隔

### 其他
- 主界面操作方式切换按钮（图标即状态）、问号使用指南（含 PC 端下载链接）、绿点进入网络拓扑
- 设置页显示手机端/PC 端版本号，提供检查更新与项目主页入口
- mDNS 自动发现：打开 App 即自动连上 PC，零配置

## 升级说明

1. PC 端：解压 zip，运行 `SpenTabletHost.exe`（v1.0.0 用户直接覆盖）
2. 手机端：安装 APK 覆盖安装（配置自动保留）
3. 两端版本需配套，建议同时升级

## 已知说明

- 手机端 APK 为 debug 签名（功能完整，可直接安装）
- PC 端为**自包含单文件**（内置 .NET 8 运行时，解压双击即可运行，无需安装任何依赖）
