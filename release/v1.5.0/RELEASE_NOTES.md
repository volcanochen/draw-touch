# draw&touch v1.5.0

本次围绕「双指平移」做了一次彻底重做：对齐真实触摸板的硬件行为，并修掉平移方向反了的问题。

## 双指平移（核心变更）

- **指针 = pan 起点 + 你的鼠标位移**（对齐硬件实测：真触摸板 pan 期间光标 100% 由物理鼠标驱动）。pan 期间鼠标照常可用、不跳触点、不被拽回。
- **抬手收尾零干扰**：抬手后覆盖系统触摸提升渲染，但只要你一动物理鼠标立即停手（三重让路：钩子判据 / 光标离触点即停 / 1.5s 硬超时），不再有"指针原地打转"或"操作丢失延迟"。
- **方向修正**：触摸注入路径纵向取反奇数次导致的"滚动方向反了"已修正，默认内容跟手指走。
- **新配置 `PanDirection`**（PC `appsettings.json`，重启宿主生效）：`InvertY` / `InvertX` / `Invert`，只影响双指平移，单指滚动不受影响。
- **手机端新增设置**：「双指平移方式」——触摸注入（默认）/ 滚轮。
- 协议升级到 v4（新增 `MOUSE_PAN` 专属帧），**两端必须同时更新**。

## 稳定性

- 低级鼠标钩子被系统静默摘除时自动检测并重装（pan 期间 500ms 心跳自检）。
- 单指滚动、捏合缩放路径未受影响（`MOUSE_SCROLL` 仍走滚轮）。
