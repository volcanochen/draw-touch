# v1.3.1 发布说明

发布日期：2026-10-28

## 🐛 本轮修复（用户实测反馈的 4 个问题）

### 1. 捕获桌面（PC 端链路验证 + 回归锁定）

- 经**协议级冒烟测试**验证：SHOT_REQ → PC 截取范围框 → PNG 分片回传 → 手机重组，全链路正常（自动化断言截图为合法 PNG）
- 此前"捕获不工作"的体感很可能来自问题 4（切模式后左键锁死导致界面无响应），随问题 4 一并修复

### 2. 悬浮按钮转屏后跑到屏幕外

- 根因：Android 转屏时 Activity 不重建，浮动面板残留**旧方向的像素坐标**导致越界
- 修复：面板 `onLayout` 自动**钳制回父容器可见范围**；转屏时按新方向**等比例还原**位置
- 横屏 / 竖屏随意切换，按钮永远在可见范围内

### 3. 荧光笔 → **激光笔**（更名 + 造型重做）

- 旧"荧光笔"图标是笔的形状、会留笔迹，与实际行为不符
- 更名「**激光笔**」，指针造型重做为**激光光斑**：白热核心 + 彩色光晕 + 亮环，指哪照哪、不留痕迹
- 换色交互不变：长按换颜色（黄 → 绿 → 粉 → 蓝）

### 4. 数位板切回触摸板后控制不了鼠标（重点修复）

三重根因全部修复：

- **PC 端触摸注入常量错误**：POINTER_FLAGS 的 DOWN/UPDATE/UP 位值全部用错（0x1/0x2/0x4），
  且捏合结束**从没发过 UP 帧** → 系统里残留一个"永远按着的触摸接触点"，等效**左键锁死**
  （常量已按官方文档修正为 0x10000/0x20000/0x40000，结束捏合补发真正的 UP 帧）
- **S Pen 悬停流抢光标**：触摸板模式下 S Pen 悬停事件仍在以绝对定位拽光标，手指移动被覆盖
  → 触摸板模式下不再转发悬停流（设置里「悬停转发」仅数位板模式生效）
- **切换瞬间状态残留**：手机端切模式即补发"松开所有键 + 手指离板"（`resetGestures`）；
  PC 端切模式强制结束挂着的触摸捏合并释放左键（`EndTouchZoomIfActive` + `ReleaseAll`）

## 🤏 触摸捏合缩放的兼容性熔断

- 部分新版 Windows（实测 Win11 Build 26300）触摸注入全组合返回 err=87（系统级限制）
- PC 端改为**连续失败 3 次自动熔断**，本机永久回退 Ctrl + +/-，不再反复报错刷日志；正常机器仍走真实触摸捏合
