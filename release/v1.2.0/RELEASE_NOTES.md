# SpenTablet v1.2.0

手机端 `1.2.0`（versionCode 4）· PC 端 `1.2.0`。两端需同时升级（协议新增动作码与换色指令）。

## 下载

- `SpenTabletPhone-1.2.0.apk` —— 手机端，安装即可
- `SpenTabletHost-win64-1.2.0.zip` —— PC 端，解压运行 `SpenTabletHost.exe`（自包含单文件，免装 .NET）

## 本次更新

### 触摸板模式

- **浮动 UI**：右侧滚轮条、底部左/中/右键全部改成浮动圆钮/浮条；进设置页、拓扑页、指南页时**自动隐藏**
- **双指捏合**成为独立可配手势槽（默认缩放 Ctrl+滚轮），松开后有 320ms 冷却，避免与滚动打架
- **可选动作扩充**：新增音量+、音量−、静音、下一任务（Alt+Tab）、上一任务（Alt+Shift+Tab）
- **默认手感调整**：光标速度默认 **1.5**，滚动比例默认 **3.0**（老用户升级后自动迁移一次）
- **无极滚动**：右侧滚轮条**双击**在「普通滚动 / 无极滚动」间切换；无极模式抬手后按动量继续滑，动量倍率可在设置里配（0.2~3.0）
- 慢速移动不飘不丢：补全 Android 合并的历史采样点 + 亚像素位移跨帧累积

### 数位板模式

- **工具条改浮动**：备注 / 撤销 / 捕获 三枚浮动圆钮居中排布，进其它页面自动隐藏
- **捕获 = 设为画布背景**：点「捕获」把 PC 范围框画面直接设成手机画布背景（不再弹新窗口），背景之上可以和白底一样继续书写绘画；再点一次清除背景并解锁范围框
- **笔迹锚定桌面原位置**：每一笔落笔时锁定桌面绝对坐标，之后移动/缩放范围框，已有笔迹**留在原地、不跟着拉伸**
- **颜色按笔记忆**：左侧浮出 7 色板，换色**只影响之后落的新笔**，已画的每笔保留自己的颜色；选择会记住并在连上时同步给 PC
- **「清除」改名「撤销」**：点击撤销一笔，长按清空

## 协议变更

| 帧 | 变更 |
| --- | --- |
| `MOUSE (0x03)` | 动作码新增 `10` 音量+ / `11` 音量− / `12` 静音 / `13` 下一任务 / `14` 上一任务 |
| `NOTE (0x0D)` | action 新增 `4` = 换色，`arg` 承载颜色索引（0~6） |

## 升级注意

- 两端版本不一致时握手会以 PC 端为准，建议都升到 1.2.0
- 老配置会自动迁移一次新的默认速度/滚动值，之后以你手动设的为准
