# v1.3.0 发布说明

发布日期：2026-10-28

## 🖍 荧光笔（新功能）

触摸板模式新增**桌面荧光笔**：点浮动面板上的「荧光笔」按钮，桌面指针立刻变成一支半透明荧光笔，
走过的地方留下荧光痕迹（透明置顶、鼠标穿透，不影响正常操作），适合网课 / 会议圈重点。

- 长按「荧光笔」按钮换颜色：黄 → 绿 → 粉 → 蓝
- 再点一下关闭，指针恢复普通箭头

## 🎛 浮动面板大合并（触摸板模式）

「荧光笔 + 左键 + 中键 + 右键」**合并成一个可整体拖动的浮动面板**：

- 挡住画面就按住面板任意位置拖走，位置会记住（转屏后按比例还原）
- 点击（不拖动）照常触发对应按键

## ✨ 所有按键都有视觉反馈

- 浮动面板上的荧光笔 / 左 / 中 / 右键，被**手指点击**或被**手势触发**时，按钮会**闪烁高亮一下**——
  三指下滑打了左键、三指上滑打了中键，现在一眼就能看出来打中了哪个键
- 数位板工具条的备注 / 撤销 / 捕获 / 色块点击同样有闪烁反馈

## 🤏 双指捏合优先「真实触摸板缩放」

- 双指捏合现在**优先注入真实的多点触摸**（等价于精密触摸板的双指捏合缩放），
  在支持的应用（绘图软件、浏览器、地图等）里是原生的 pinch-zoom 手势，不再是模拟 Ctrl+滚轮
- 系统不支持时自动回退 Ctrl + +/-；PC 端设置里也可手动选择「触摸板缩放 / 按键缩放」

## 👆 三指 / 四指滑动拆分四方向，手势槽从 7 个变 13 个

- 三指左 / 右 / 上 / 下滑、四指左 / 右 / 上 / 下滑**各自独立配置**（原来只有左右）
- 默认值：三指右滑=前进、左滑=后退、上滑=中键、下滑=左键；四指右滑=切换模式、
  上滑=音量+、下滑=音量-、左滑=无
- 设置页逐个点击切换动作，可选动作与之前一致（左中右键、后退前进、缩放、音量、静音、任务切换、切换模式）

## 🔄 检查更新直连 GitHub Releases

- 设置页「检查更新」现在**直接比对 GitHub Release 的最新版本号**：有新版时弹窗提示更新内容，
  确认后**自动下载 APK 并拉起系统安装**，不用再去网页手动下载
- App 启动时也会静默检查（仅发现新版才提示，不打扰）

## 📜 其他改进

- **拓扑页可滚动**：屏幕小、发现的主机多时也能看完，不再被截断；拓扑图内文字与其他文字同大
- 修复方向滑动可能导致的浮动键反馈异常；无极滚动惯性初速改用抬手瞬间真实滑动速度
